# 初次索引

从零创建、修复或继续未完成的 AI 上下文索引。公共约束、基线和输出契约见 [SKILL.md](../SKILL.md)。

## 1. 建立可恢复断点

先读取目标范围内已有的 `AGENTS.md` 与 `CLAUDE.md`，确认索引层级并保存需要保留或迁移的人工内容，按公共输出契约整理旧记录。用户明确仅维护根文档时，模块信息写入根索引，不创建模块文档。新一轮扫描把候选起点保存在唯一的「扫描进度」字段中，完成前保留旧全局基线；续扫只更新已有断点，不覆盖其原始起点：

```markdown
## 索引状态
- 上次索引：<保留旧全局 UTC 起点；尚未建立则写“无”>
- 基线提交：<保留旧完整 commit；尚未建立或非 Git 项目写“无”>
- 已知缺口：<当前尚未覆盖的索引内容>
- 扫描进度：未完成；起点=<原始 UTC 时间、完整 HEAD 或“无”>；已完成=<模块集合或“无”>；待处理=<根级清点或模块集合>
```

若已有未完成状态，按约定层级核对已完成模块的实际落盘位置：模块级模式检查该模块的 `AGENTS.md` 与 `CLAUDE.md`，仅根级模式检查根 `AGENTS.md` 中对应模块的信息。只有适用输出契约已满足且内容已落盘，才保留该模块的已完成状态。利用原始起点以来的变化证据，定向核对已完成模块中受影响的部分，需要补查的模块回到待处理；不因续扫重读全部源码。

旧断点缺少可核实的起点时，保留可信旧基线及已落盘内容，将覆盖不确定的部分记为待核对。只有重新核对约定范围时才建立新起点，不能用当前时间或 HEAD 替换未知的旧起点并跳过已标完成的模块。

## 2. 轻量清点

分批列出非忽略文件，不读取依赖目录或生成物。Git 项目优先使用 Git 文件清单；非 Git 项目使用当前宿主可用且遵守嵌套忽略规则的文件列举能力。完成以下清点：

- 文件数量、主要语言和目录拓扑；
- 根 manifest、workspace 配置、README 与开发/测试配置；
- 模块候选：语言 manifest、`apps/*`、`packages/*`、`services/*`、`cmd/*` 及仓库实际采用的其他边界；
- 每个候选模块的语言、可能入口、测试和配置。

候选目录不等于模块：以独立职责、入口/manifest、构建或发布边界为证据确认，避免给每个普通源码目录都生成文档。

首次清点时初始化模块进度；续扫时保留核实后的已完成集合，仅将新增、变化或覆盖不确定的模块加入待处理。始终保留原始起点，并原位更新当前进度。

## 3. 按模块扫描并立即落盘

逐个待处理模块定点读取高信号文件：

1. 入口和启动脚本；
2. 路由、控制器、公开导出、协议或 API 定义；
3. 依赖、workspace、构建与质量配置；
4. schema、模型和迁移；
5. 测试入口与代表性测试；
6. 仍有效的模块级 `AGENTS.md` 或长 `CLAUDE.md` 人工说明。

每完成一个模块，先按约定层级落盘：

- **模块级模式**：写入或段落级更新该模块 `AGENTS.md`；先迁移长 `CLAUDE.md` 的有效内容，再将该模块 `CLAUDE.md` 收敛为一行 `@AGENTS.md`。
- **仅根级模式**：写入或段落级更新根 `AGENTS.md` 中对应模块的信息，不创建或改写模块文档。

复读本次实际写入的文档，确认适用输出契约和人工内容均保留，最后更新根「扫描进度」，把该模块从待处理移到已完成。

每处修改先与现有内容比较，准确且完整的内容保持原样。不要先推进断点再写索引内容，否则中断后会错误跳过尚未持久化的扫描结果。

## 4. 按需补捞

仅在以下情况扩大读取范围：关键职责、接口、数据或测试仍无法判断；现有人工文档提出了尚未核实的事实。只读取解决缺口所需的文件，不粘贴大段源码。

若工具、时间或上下文不足，保留旧全局基线与原始扫描起点，将唯一的进度快照标为未完成，更新当前已完成模块、待处理模块、索引缺口和阻塞原因。已完成模块的索引内容应已按约定层级落盘，下一次核对这些实际产物后从待处理列表继续。

## 5. 完成根文档

全部模块完成后：

1. 将根长 `CLAUDE.md` 和旧 `AGENTS.md` 的有效人工内容去重合并到根 `AGENTS.md`；
2. 根据真实模块生成架构、Mermaid 链接和模块索引；
3. 更新运行、测试、规范和 AI 指引中的当前事实；
4. 将本轮原始起点写入全局时间与 commit 字段；索引缺口已补齐则写“无”，扫描进度只保留“已完成”，移除临时起点与过程列表；
5. 复读根 `AGENTS.md`，确认「索引状态」只有一份且位于文档最末、各字段唯一，正文与状态中没有新增历史流水；
6. 最后把根 `CLAUDE.md` 收敛为一行 `@AGENTS.md`。

## 6. 报告覆盖

分别报告“已列举”和“已实际读取内容”的文件数，避免把只看到路径误报为已扫描内容。列出已完成模块、未读目录、二进制/大文件和主要缺口；覆盖率只写进主对话，不把统计噪声写入文档。
